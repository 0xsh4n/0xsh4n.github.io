About 0xsh4n

Offensive security work with a focus on how real applications fail in production.

I'm an Associate Security Analyst working on web, API, and mobile application security. Day to day that means hands on testing with Burp Suite and similar tooling, looking for auth issues, broken access control, and messy business logic.

Alongside full time work, I take on freelance security engagements. Short VAPT projects, targeted AppSec reviews, and mobile assessments for teams that need an extra set of offensive eyes.
